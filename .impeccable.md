## Design Context

### Users

Nebulens serves individual creators and small creative teams who generate, compare, revisit, download, and manage AI imagery in a focused desktop workflow. Administrators also use the product to create accounts and manage daily generation quotas. The interface must keep prompt entry, reference-image upload, generation controls, recent outputs, asset history, authentication, and user administration immediately usable.

### Brand Personality

Precise, fluid, and quietly inventive. Nebulens should feel like a premium dark AI image studio built from layered graphite surfaces, compact controls, and continuous morphing interactions. The product voice is concise Simplified Chinese, with clear labels and no marketing filler inside task surfaces.

### Aesthetic Direction

Use the beUI Pro-derived `design.md` as the visual source of truth. Default to a dark AI studio with semantic shadcn-style graphite surfaces, 8-20px role-based radii, restrained floating shadows, compact toolbars, animated dropdowns, morphing card-to-modal transitions, and a prompt-first Agent Composer. Generated imagery and the existing logo provide color. Keep an optional light token set, but all routes open in dark mode. Avoid copying Squarespace composition, generic SaaS metric dashboards, decorative gradients, repeated card grids, oversized marketing copy inside task surfaces, and glow around components.

### Design Principles

1. Make the image workflow faster to scan and operate than the current UI; atmosphere must never compete with prompts, settings, results, or asset actions.
2. Use one semantic beUI/shadcn system across every route, with shared surfaces, controls, menus, tooltips, and modal behavior.
3. Keep the workspaces dark-first and layered; use light inversion for primary actions while generated imagery provides chroma.
4. Preserve complete behavior, accessibility labels, keyboard focus, reduced-motion support, and responsive mobile workflows during visual restructuring.
5. Let real generated imagery, the existing logo, and the home-page video carry the visual identity; do not fake visible assets with CSS illustrations.
