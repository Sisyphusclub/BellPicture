# 修复输入框光效四角断层

## Goal

修复 Generate 与 Discover 共用输入框在四个圆角处出现的双线、断层和半径不连续问题，同时保留现有橙、青、蓝配色和方向性外发光。

## Requirements

- 共享 `BorderGlow` 必须继续作为两个路由唯一的光效实现。
- 彩色结构边框、静态边框与外发光源必须沿同一条圆角路径绘制。
- 外发光遮罩需要保留足够的扩散空间，不能裁掉 `box-shadow`。
- 不改动输入框内容布局、交互状态、配色和 reduced-motion 行为。

## Acceptance Criteria

- [x] Generate 输入框四个圆角没有内外双线或可见断点。
- [x] Discover 输入框复用同一修复，无路由级光效算法分叉。
- [x] 聚焦、悬停和失焦状态保持现有透明度过渡。
- [x] 1440px 桌面和 390px 移动视口无横向溢出或布局回归。
- [x] 前端组件检查、类型检查、lint、测试和构建通过。

## Definition of Done

- 浏览器在真实页面上验证四角、焦点状态、桌面和移动布局。
- 记录导致断层的分层圆角几何约束。
- 只提交本任务相关文件，不包含并行工作区改动。

## Technical Approach

绝对定位伪元素从父元素内边缘建立包含块。将彩色边框向外移动一个结构边框宽度；外发光容器继续为阴影预留空间，但其半径等于本体半径与扩散距离之和；内部发光源显式使用本体半径。这样三层共用同一条边框路径，方向遮罩仍可覆盖完整阴影。

## Decision (ADR-lite)

**Context**: 先前仅移除方向遮罩或内描边，没有修正放大遮罩层、内缩发光源和静态边框之间的坐标差异。

**Decision**: 修复共享组件的几何契约，不在 Generate 或 Discover 中添加补丁。

**Consequences**: 光效算法仍只有一份；后续调整半径或光晕距离时，外层半径和发光源半径会自动保持同心。

## Out of Scope

- 调整输入框配色、尺寸或内容排版。
- 修改模板、历史、生成接口或其它并行工作。
