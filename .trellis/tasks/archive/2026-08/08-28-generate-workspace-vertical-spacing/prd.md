# 调整生成工作区垂直布局

## Goal

调整 Generate 工作区有结果时的垂直空间分配，让会话内容不再贴近页面顶部，同时缩短固定创作输入框与视口底部之间的无效留白，形成更紧凑、结果优先的工作台节奏。

## Requirements

- 桌面端会话结果流顶部需要明显下移，并随视口高度在受限范围内自适应。
- 固定创作输入框距桌面视口底部使用紧凑但可辨识的安全距离。
- 移动端继续避让底部导航栏与 `safe-area-inset-bottom`，只收紧额外留白。
- 保持结果流、提示词气泡、生成占位图和固定输入框原有横向轴线。
- 不修改 beUI Agent Chat Input 的内部尺寸、控件、生成行为或滚动到最新结果逻辑。
- 空状态仍保持当前居中构图，不应用有结果状态的顶部节奏。

## Acceptance Criteria

- [x] 1440 x 813 有结果状态下，会话内容顶部间距位于 `64-112px` 范围内，不再贴近顶部工具区。
- [x] 桌面固定输入框下沿距视口底部为 `16px`，无多余空白且不贴边。
- [x] 390 x 844 下固定输入框避开底部导航和安全区，额外间距为 `16px`。
- [x] 390 x 844 下首个会话批次位于顶部导航下方，不发生遮挡。
- [x] 最后一批结果可滚动到输入框上方，结果操作不被固定输入框遮挡。
- [x] 空状态构图和输入框位置不发生回归。
- [x] 页面无横向溢出，控制台无新增错误或警告。
- [x] 组件检查、类型检查、lint、测试和构建通过。

## Definition of Done

- 在桌面和移动端分别测量结果流顶部、输入框底部和结果/输入框安全间距。
- 对比同一视口修改前后的 Generate 页面截图。
- 运行前端组件检查、类型检查、lint、测试、构建、目标格式检查和 `git diff --check`。
- 按仓库提交规范提交并归档任务。

## Technical Approach

在 `frontend/src/styles/base.css` 的 Generate 最终级联层中调整页面级布局：桌面有结果状态的 `.session-feed` 使用 `clamp(64px, 9svh, 112px)` 顶部内边距；固定 `.studio-create-bar` 的桌面附加底距由 `36px` 调整为 `16px`，移动端相应保留 `74px` 导航栏与安全区并将附加底距调整为 `16px`。

## Decision (ADR-lite)

**Context**: 当前顶部只使用 `26px` 固定内边距，在高视口中显得贴顶；输入框底部固定 `36px`，造成工作台底部无效留白。

**Decision**: 顶部采用受限的视口相对间距，底部采用 4pt 间距体系中的 `16px`。只调整页面定位层，不修改输入组件和结果卡片。

**Consequences**: 高视口中的会话内容获得更稳定的视觉重心；输入框更贴近工作区底部。移动端仍由导航栏和安全区决定主要避让距离。

## Out of Scope

- 不调整结果卡片尺寸、生成占位动画或提示词气泡样式。
- 不改变输入框高度、工具栏换行、提交按钮或积分状态。
- 不重构现有 Generate CSS 历史级联。
