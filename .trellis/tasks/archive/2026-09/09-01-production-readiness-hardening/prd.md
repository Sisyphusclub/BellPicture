# 正式上线阻塞项修复

## 目标

将 Nebulens 从受控内测状态提升到可进行公网灰度发布的工程基线，并保留现有产品视觉与交互行为。

## 范围

1. 保证生成图片文件与 SQLite 历史记录一致：持久化失败必须回滚文件并返回失败；删除历史时同步清理文件；提供现有孤立文件盘点/恢复机制。
2. 私有输出图片只允许所有者或管理员访问，公开图片保持匿名可读；OpenAI-compatible URL 输出继续可用且使用受控访问方式。
3. 升级存在已知高危漏洞的生产依赖，增加认证、注册、上传、生图和 `/v1` 接口的限流与基础安全响应头。
4. 收紧生产 Compose：前端同源 API 默认值、后端端口暴露、外部 provider 网络和健康检查必须适合可重复部署；补充 TLS、备份与恢复说明。
5. 减少首屏 JS 与图片 DOM：路由代码拆分，发现页和模板页分批渲染，避免同时渲染桌面/移动两套完整画廊，保留全部 163 个模板可访问。
6. 移动端交互目标不小于 44px，画廊可访问名称使用简洁标题而不是完整提示词。
7. 增加 CI 发布门禁，修正文档技术栈与存储说明，保证格式、lint、类型、测试和构建通过。

## 非目标

- 不改变现有 beUI 视觉方向、生成模型能力、额度业务规则或管理员权限模型。
- 不删除现有输出图片或用户数据；孤立文件只盘点和恢复，不做破坏性清理。
- 不在本任务中采购域名、证书、云存储或外部监控服务。

## 验收标准

- 模拟数据库写入失败时，生成接口返回错误且新输出文件被清理。
- 私有图片匿名访问返回 401/404；所有者、管理员和公开图片访问正常。
- 历史单删、批量删、批次删同步删除对应文件，并覆盖失败回滚/日志路径。
- `npm audit --omit=dev --audit-level=high` 不再报告可利用的生产高危依赖。
- 限流返回结构化 429，并带请求编号；安全响应头存在。
- 前后端 build、typecheck、lint、test、format:check 全部通过。
- 首页初始只渲染一套画廊，模板和发现页通过“加载更多”逐步展示全集。
- 390px 视口无横向溢出，主要图标按钮最小 44x44px。
- CI 工作流覆盖安装、审计、格式、lint、类型、测试和构建。
- 每个独立修复形成中文 `fix:` 或 `feat:` 提交，最终推送到 `origin/dev`。
