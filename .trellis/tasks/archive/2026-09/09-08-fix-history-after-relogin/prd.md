# 修复重新登录后生图历史消失

## Goal

让用户在生图页退出登录并使用同一账号重新登录后，工作区能够再次依据当前账号的服务端历史恢复最近会话，不再错误地保持空白状态。

## Root Cause

- 裸 `/generate` 的自动恢复使用组件生命周期级别的布尔门闩。
- 首次进入页面后门闩会被标记为已处理；退出登录时组件仍挂载，门闩没有随认证周期重置。
- 同一账号重新登录后，即使 `useImageHistory` 已重新水合服务端记录，恢复 effect 仍被旧门闩提前拦截。

## Requirements

- 未认证状态必须清除裸路由恢复门闩，为下一次登录建立新的恢复周期。
- 同一账号重新登录后，裸 `/generate` 必须等待当前账号历史水合完成，再恢复有效缓存会话或从服务端批次重建会话。
- 不允许在退出期间显示上一认证周期的记录，也不能跨账号恢复会话。
- 显式 `session`、提示词交接和自动生成入口继续优先于裸路由自动恢复。
- 不修改服务端历史数据、历史 API 或数据库结构。

## Acceptance Criteria

- [x] 已登录用户在裸 `/generate` 完成首次初始化后退出，再用同一账号登录，服务端历史重新出现在生图工作区。
- [x] 重登恢复仍以当前账号已水合的历史为准。
- [x] 原有跨标签页、服务端重建、账号隔离、提示词和自动生成路由测试继续通过。
- [x] 前端组件检查、类型检查、lint、测试、构建、格式和 Git whitespace 检查通过。

## Out of Scope

- 不迁移或修改 `image_records` 与生成文件。
- 不新增服务端会话表或修改认证接口。
- 不改变历史删除、生成提交或资产页交互。
