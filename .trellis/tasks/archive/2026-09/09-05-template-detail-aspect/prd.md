# 模板详情按原图比例布局

## Goal
消除模板详情固定图片区造成的黑边，保留整张原图、不裁切不拉伸。

## Requirements
- 桌面利用模板真实 width/height 计算图片区与弹窗尺寸，受视口宽高约束。
- 详情栏独立滚动，不再撑高图片区；关闭、复制、收藏、使用模板仍可操作。
- 手机按原比例显示图片，详情排在下方，弹窗整体可滚动。
- 不修改模板列表、其他详情弹窗和原图内容。

## Acceptance
- [x] 横图、竖图、方图图片区与原图比例一致。
- [x] 桌面弹窗在视口内且详情滚动不移动图片。
- [x] 手机无横向溢出，关闭按钮和所有操作可访问。
- [x] 前端测试、类型、lint、构建、格式检查及浏览器检查通过。

## Approach
复用模板清单宽高，通过 section CSS 自定义属性驱动桌面受限尺寸。移除旧固定高规则，手机使用自然图片高度，保留共用 MorphicCardModal。

## Verification
- 前端 34 个套件、137 项测试通过；typecheck、lint、build、format:check 通过。
- Chromium 在 1440x813、1024x768、390x844、320x740 验证三种原图比例，共 12 个组合。
- 自然图片比例与媒体容器一致，高度差小于 1px，无水平溢出；桌面详情滚动不移动图片。
- 使用 document.body Portal 修复页面堆叠上下文遮挡。手机详情滚动后关闭按钮可点击，Escape 正常关闭。
- 截图保存在 /tmp/template-detail-{width}-{index}.png。
