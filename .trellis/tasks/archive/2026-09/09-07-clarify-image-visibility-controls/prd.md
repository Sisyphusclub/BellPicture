# 统一图片可见范围文案

## Goal

消除“公开 / 私有”在生成开关、资产状态和操作按钮中的方向歧义，让用户明确知道作品是否会出现在站内发现页，以及点击按钮后会发生什么。

## What I already know

- 首页生图开关已采用 `checked = isPublic`，生成工作台当前采用相反的 `checked = !isPublic`。
- 生成结果、资产网格、资产列表和图片详情都使用“设为公开 / 设为私有”，同时复用当前状态图标表达下一步动作。
- 用户已确认采用“发布到发现页”“发现页可见 / 仅自己可见”“从发现页移除”这套语义。

## Requirements

- 首页与生成工作台的开关都以开启表示“发布到发现页”，并使用相同的可访问名称和固定文案。
- 状态文案统一为“发现页可见 / 仅自己可见”。
- 操作文案统一为“发布到发现页 / 从发现页移除”，图标表达动作而不是当前状态。
- 资产筛选统一为“全部范围 / 发现页可见 / 仅自己可见”。
- 图片详情字段名称改为“可见范围”。
- 更新成功反馈明确说明作品已发布或已从发现页移除。
- 不修改 `isPublic` API、URL 参数、持久化结构或后端权限语义。

## Acceptance Criteria

- [ ] 首页和生成工作台的“发布到发现页”开关方向一致，默认关闭时均表示仅自己可见。
- [ ] 生成结果、资产网格、资产列表和图片详情的动作标签一致。
- [ ] 资产筛选、列表状态、详情元数据和生成历史预览使用统一状态文案。
- [ ] 相关组件和路由测试覆盖正向开关与动作标签。
- [ ] 桌面和移动布局中文案不溢出、不遮挡，浏览器控制台无新增错误。

## Definition of Done

- 前端组件测试、类型检查、Lint、格式检查和构建通过。
- 桌面 1440 × 813 与移动 390 × 844 完成浏览器复核。
- 变更以独立 Git 提交交付，不夹带现有无关工作区改动。

## Out of Scope

- 后端字段重命名或数据库迁移。
- 发现页访问策略、分享链接和权限模型调整。
- 与可见范围无关的页面视觉重构。

## Technical Notes

- 共享文案放在前端工具模块，所有受影响组件从同一来源读取。
- 使用 Lucide `Globe2` 表示发布到发现页，使用 `EyeOff` 表示从发现页移除，`Lock` 仅表示当前为仅自己可见。
- 现有 CSS 类名可保留作为稳定样式契约；仅在长文案实测溢出时调整尺寸。
