# Generate Nebulens Logo with gpt-image-2

## Goal

Generate a new raster logo mark for Nebulens with `gpt-image-2` through the `openai-image-api` workflow, convert it to a clean transparent PNG, and replace the temporary text monogram in the application sidebar.

## Requirements

* Use `gpt-image-2` through `scripts/image_api.py`; do not silently downgrade the model.
* Design one text-free, compact mark that combines an abstract lens/aperture, a restrained orbital or nebula motion, and an implied `N` silhouette.
* Match the product personality: minimal, editorial, exacting, calm, premium, and task-focused.
* Use a strong silhouette with limited detail so the mark remains legible at 42px and 32px.
* Use a flat chroma-key background for local transparency removal because `gpt-image-2` does not provide native transparent output.
* Produce the committed asset at `frontend/public/brand/logo.png` and reference it from `AppHeader.vue`.
* Keep generated source and chroma-key intermediates outside the committed repository.

## Acceptance Criteria

* [x] The provider output is generated by `gpt-image-2` and visually inspected.
* [x] The final PNG has an alpha channel, transparent corners, clean antialiased edges, and no visible key-color fringe.
* [x] The committed logo has exact square dimensions suitable for the sidebar and is not blank.
* [x] No text, watermark, extra icon, or unintended background remains in the asset.
* [x] `AppHeader` renders `/brand/logo.png` with a descriptive Nebulens alt label.
* [x] Header tests, frontend lint, typecheck, build, and browser visual checks pass.
* [x] Git status contains only the intended logo, code, test, spec, and Trellis artifacts.

## Definition of Done

* The image request, post-processing, and actual output dimensions are recorded.
* The image is verified at source size and rendered sidebar size.
* Relevant automated checks pass.
* The work is committed locally and the Trellis task is archived.

## Technical Approach

Generate one high-quality 1024x1024 PNG on a flat `#00ff00` background. Remove the background using `remove_chroma_key.py` with soft matte and despill, then use `resize_image.py` to create an exact 256x256 PNG for the frontend. Restore the existing fixed public asset path and cache-busting URL pattern only where needed by the live component.

## Decision (ADR-lite)

**Context**: The prior brand asset was removed during the Nebulens rename, leaving a temporary CSS `N` monogram.

**Decision**: Create a new raster mark with `gpt-image-2`, then derive transparency locally through chroma-key removal as required by the selected model.

**Consequences**: The final asset is raster rather than an editable vector. A future formal identity project may replace it without changing the public asset contract.

## Out of Scope

* Generating multiple variants or a full brand system.
* Adding a wordmark, slogan, or in-image text.
* Changing the broader UI palette or layout.
* Using `gpt-image-1.5` native transparency.

## Technical Notes

* User explicitly requested the `openai-image-api` Skill and `gpt-image-2`.
* Brand context comes from `PRODUCT.md`.
* The live sidebar mark is currently 42px on desktop and 32px on mobile.
* The Image API request asked for 1024x1024 high-quality PNG, but the provider returned 1254x1254. The strict size check surfaced the mismatch; no native-size claim is made.
* Chroma-key removal auto-detected `#12f50e`, removed 1,297,853 of 1,572,516 provider pixels as fully transparent, and retained 8,880 partially transparent edge pixels before resizing.
* Final asset: 256x256 RGBA PNG, 24,160 bytes, alpha bounding box `(35, 50, 221, 208)`, 52,112 transparent pixels, 4,344 partially transparent pixels, 9,080 opaque pixels, zero visible greenish pixels, and four fully transparent corners.
* Browser verification: source `/brand/logo.png`, natural dimensions 256x256, rendered approximately 42x42 desktop and 32x32 at the mobile breakpoint, with no console warnings or errors.
