# 本地启动与上线前审计

## Goal

在本机启动 Nebulens 前后端，验证核心页面、健康检查、质量命令和生产构建，并基于可复现证据判断当前版本是否适合上线。

## What I Already Know

- 项目由 React/Vite 前端与 Express/TypeScript 后端组成。
- 本地开发端口为前端 `5173`、后端 `3000`。
- Node.js `v24.14.0` 满足前后端 engines 要求，依赖目录已存在。
- 本机未安装 Docker，因此不能执行 Compose 镜像级验证。
- 本地 `.env` 尚未创建；真实上游图片生成凭据不可假设存在。
- 工作区已有与本任务无关的未提交 `.codex/config.toml` 及未跟踪 skill 目录。

## Assumptions

- 可以用本地专用占位上游配置启动服务并验证非生图路径；真实生图调用单独标为未验证。
- 初始审计只报告问题；用户确认“接着修改”后，任务继续修复可在仓库内闭环的上线问题。
- 服务在验证完成后继续运行，方便用户本机访问。

## Requirements

- 基于示例文件创建仅供本机使用、被 Git 忽略的运行配置。
- 启动后端和前端，记录进程、端口与日志。
- 验证 `/api/health/live`、`/api/health/ready` 和主要前端路由。
- 执行前后端 lint、typecheck、test、build/format check 等现有质量命令。
- 进行浏览器桌面与移动视口烟测，检查控制台、网络、可见布局和基本可访问性。
- 审查生产配置、安全边界、持久化、部署、依赖和仓库卫生。
- 输出按 P0-P3 排序的上线阻塞项与结论。
- 将首页共享 Logo 缩放为适合实际渲染槽位的透明 PNG，并用文件尺寸和像素尺寸回归测试约束。
- 为生产 Nginx 的所有响应路径补充一致的 Content Security Policy。
- 在粗指针设备上将审计发现的紧凑图标操作扩大到至少 `44px` 触控区域，同时保留桌面密度。
- 通过 `APP_VERSION` 环境变量注入发布标识，并让健康接口返回该标识。
- 修正 Discover 瀑布流横向 `6px`、纵向 `12px` 的间距不一致，统一为紧凑的 `6px` gutter。
- 修正 Generate 桌面画布按展开侧栏宽度单边避让造成的右偏，让输入框与结果流相对视口居中。
- 放宽创作模板桌面详情弹窗并限制其视口高度，让图片完整可见且提示词信息栏保持可读宽度。
- 修复 Discover 输入框从 hero 停靠到底部、以及紧凑态展开为编辑态时的瞬移和左上角突现，并只保留状态锚点这一层布局投影。
- 统一 Generate 最终画布覆盖层与 Templates/Assets operational canvas 的点阵颜色、半径、位置及桌面/移动间距。

## Acceptance Criteria

- [ ] 前后端服务均监听预期端口，用户可访问 `http://localhost:5173`。
- [ ] 健康检查返回并记录真实状态。
- [ ] 所有项目质量命令均有退出状态和关键输出记录。
- [ ] 浏览器至少检查一个桌面视口和一个移动视口。
- [ ] 明确列出未验证范围，包括真实图像生成与 Docker Compose。
- [ ] 给出可复现的回滚脚本与验证记录。
- [ ] 给出明确上线结论和按优先级排序的修复建议。
- [ ] Logo 不超过 `512x512` 和 `100 KiB`，且视觉透明度与现有品牌资产保持一致。
- [ ] 生产 Nginx 所有自定义 `add_header` 作用域均包含 CSP。
- [ ] 粗指针设备上的目标操作尺寸至少为 `44px`。
- [ ] `APP_VERSION` 默认值、显式配置、Compose 注入和健康响应均有测试或静态契约验证。
- [ ] Discover 瀑布流的列间距与直属 `figure` 下边距均为 `6px`，桌面和移动端无异常空隙。
- [ ] Generate 桌面端使用折叠导航栏 token 对称避让，空白态输入框、固定输入框和结果流中心轴一致；移动端布局不变。
- [ ] 创作模板桌面详情使用 `calc(100% - 32px)` 且最大宽度为 `1360px`，信息栏至少 `400px`，整体高度不超过视口；中等桌面无横向裁切，`<=860px` 继续使用 `100%` 全屏单列。
- [ ] Discover 输入框仅由状态锚点使用 Motion 布局投影覆盖 dock/expand 两段切换；嵌套内容使用普通 `div` 且不再持有 `layout`，避免实际输入框尺寸瞬变。
- [ ] Generate 最终点阵使用 `var(--border-strong) 46%`、`0.9px/1px` 半径、`4px 4px` 位置，并与 operational canvas 共用桌面 `20px`、移动 `16px` 尺寸。

## Definition of Done

- 运行配置、进程与端口经过验证。
- 审计证据保存在 `/private/tmp` 工件目录。
- 仅更改本任务相关代码，且未覆盖用户已有未提交改动。
- 服务保持运行，回滚脚本可停止服务并清理本地审计配置。
- 修复后的前后端质量门禁、生产构建、浏览器桌面/移动回归和健康探针全部通过。

## Out of Scope

- 不调用真实第三方图像生成服务。
- 不部署到远端或生产环境。
- 不伪造真实 Provider 凭证，也不把占位上游当作生图验证通过。
- 不在缺少 Docker 的主机上声称 Compose 运行时验证通过。
- 不提交用户已有的 `.codex/config.toml` 或 skill 目录改动。

## Technical Notes

- 根目录 `README.md` 描述本地开发、Compose、健康检查和生产部署要求。
- `.trellis/spec/backend/deployment-readiness.md` 与前后端质量规范作为审计基线。
- `audit` 技能用于前端可访问性、性能、主题、响应式和反模式评分。
