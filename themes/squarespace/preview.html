Elevation

Shadows

The observed system uses none. Contrast, imagery, spacing, and scrims carry depth.

box-shadow: none
No shadow token

Do not add an invented elevation scale. Use a hairline or change the surface value when separation is required.

Guidelines

Do's & Don'ts

Do

  • Alternate full-width black and white bands.
  • Use 72px display text with -4.32px tracking.
  • Keep buttons at 4px and cards at 8px radius.
  • Use real imagery as the source of color.
  • Separate surfaces without shadows.
  • Reserve serif type for image-card titles.
  • Use a 40% black scrim only for legibility.

Don't

  • Add a saturated CTA color.
  • Wrap every section in a floating card.
  • Turn controls into oversized pills.
  • Invent drop-shadow elevation.
  • Use serif type in operational UI.
  • Loosen display tracking.
  • Place white text over busy images without a scrim.
